# Roadmap

## Sprint 0 — base tecnica

- [x] Starter sorgente, struttura, istruzioni agenti e documentazione.
- [x] Codice catalogo/presenter e strumenti Editor.
- [ ] Import Unity senza errori; generazione e commit di scena, impostazioni e lockfile.
- [ ] ARCore attivo e Project Validation risolta.
- [ ] Primo APK installabile con camera AR, risultato registrato.
- [ ] Import della stessa revisione su Mac e Windows.

Sprint 0 non è concluso finché questi controlli pratici non sono completati.

## Sprint 1 — prima evocazione

Scegliere una carta fisica e un placeholder originale; configurare library/catalogo; provare acquisizione, posa, perdita e recupero. Aggiungere UI per permessi, AR non disponibile e istruzioni di scansione. Introdurre Unity Test Framework e test significativi per catalogo e ciclo di vita; il dispositivo resta necessario. Uscita: dimostrazione registrata sul telefono e checklist con esiti reali.

## Sprint 2 — robustezza

Espandere a poche carte, misurare falsi positivi, distanza, luce e prestazioni; verificare duplicati e limiti multi-image del provider; ottimizzare solo dai dati. Eventuali animazioni usano modelli propri o autorizzati.

## Sprint 3 — esperienza

UI e interazioni di evocazione, effetti leggeri e gestione stato. Valutare regole semplificate e altre piattaforme solo dopo una PoC stabile.
