# Prompt Codex — completare Sprint 0 nell'Editor

Lavora sul repository Duel AR e leggi AGENTS.md, README e docs/setup.md. Preserva i file esistenti. Verifica la presenza di Unity 6000.0.65f1 e dei moduli Android. Importa il progetto, risolvi eventuali errori reali senza cambiare versioni silenziosamente, esegui Configure Android e Create Sprint 0 Scene. Verifica pipeline URP/AR background, camera pose driver e loader ARCore. Salva scena, impostazioni, meta e packages-lock.json. Non includere immagini protette o chiavi di firma.

Se Editor o dispositivo mancano, completa soltanto ciò che puoi verificare e dichiara precisamente i passaggi pendenti. Con dispositivo disponibile crea una Development Build Android e registra i risultati in docs/validation.md. Verifica poi l'import sul secondo sistema operativo quando accessibile. Commit su branch e PR con prove effettive; non dichiarare una build riuscita senza eseguirla e non unire la PR.
